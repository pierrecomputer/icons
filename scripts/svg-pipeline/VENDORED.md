# SVG pipeline source

These modules were copied from `pierrecomputer/figma/packages/svg-pipeline/src`
so this repository can build icons and previews without a sibling checkout of
the private Figma repository.

Keep `artwork.ts`, `manifest.ts`, and `react.ts` aligned with the Figma exporter
until the pipeline has a single permanent home. The local `index.ts` exports
only the APIs used by this repository.
